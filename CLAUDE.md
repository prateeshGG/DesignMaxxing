# DesignMaxxing — instructions for Claude

**Start every session by reading [docs/HANDOFF.md](docs/HANDOFF.md).** It summarises the project, every decision and rejection, what exists, and what to do next.

Standing rules from the founder:
- Explain in plain, non-technical words. When a decision is needed, ask a short numbered question with a suggested answer; "ok to all" accepts every suggestion.
- Use Sonnet 5.5 for sub-agents.
- Push work to the working branch **and** fast-forward `main`.
- Do not start implementing until the founder says so.
- Never invent decisions in specs: undecided items become `OPEN QUESTION OQ-<part>-<n>` with a suggested default. Decisions live in `docs/20-founder-decisions-and-plan-validation.md`; change the source doc first.
- Public pages never describe how the library is collected. Landing style: light, editorial, soft colours with soft shadows, no solid black bars, real sharp screenshots, sites credited.
- Collection never evades blocks, honours robots.txt and rate limits, and captured never means publishable.
- Never commit secrets.
