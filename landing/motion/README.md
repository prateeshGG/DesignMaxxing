# Landing motion — how the videos are made

The landing prototype's videos are pre-rendered here, so the page itself runs no heavy animation code.

- `src/flute/scenes/*` — cinematic 3D scenes built with [Flute](https://github.com/webprodigies-org/flute) (`@webprodigies/flute`, MIT licence). Each scene is a `.scene.json` recipe plus a React binding that places real section crops (`public/img/`) on 3D surfaces. They are generated by `scripts/gen.mjs`; edit that script and run `node scripts/gen.mjs`.
  - `compare-heroes` — a camera survey across three real hero sections
  - `page-recording` — a camera travelling down one real page along its edge
  - `phones` — three real mobile sections plating into place
  - `wall` — a wall of real sections, surveyed diagonally
  - `plate` — the sections of one real page settling into place
- `silk/render-blocks.mjs` — renders the hero background: a seamless loop of a conveyor of wireframe "sections" (original artwork). `silk/render.mjs` is an earlier gradient-ribbon experiment that was dropped because it looked too much like a reference site.
- `out/` — exported MP4s (git-ignored; the published copies live in `../prototype/video/`).

## Re-rendering

```sh
cd landing/motion
npm install
npx vite --host 127.0.0.1 --port 5173 &      # the studio runs on the dev server
npx flute export --url 'http://127.0.0.1:5173/?flute-preview=1&flute-scene=compare-heroes' --output out/compare-heroes.mp4 --fps 30
```

Notes from setting this up in the cloud sandbox:
- Flute's exporter needs FFmpeg and Playwright Chromium. Flute bundles its own Playwright (1.58) inside `node_modules/@webprodigies/flute/node_modules/`; with the sandbox's pre-installed Chromium (revision 1194) the export only worked after moving that nested `playwright` and `playwright-core` aside so the project's Playwright 1.56.1 was used.
- The exported video size is 1440×1000 regardless of the 1280×800 scene size.
- Playwright's Chromium cannot decode H.264, so test pages in a real browser (or transcode a copy to WebM for headless checks).
- The crops in `public/img/` are third-party screenshots (private prototype only; see `../design-notes.md`).
