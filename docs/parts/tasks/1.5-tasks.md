- Authorization values `authorized_session` and `authorized_build`: added in V2 (OQ-1.5-3, §3.7).
- Per-source crawl budgets (GAP§8: `max_browser_minutes`, `max_video_minutes`, `max_storage`, `max_AI_cost`): not stored in V0; 2.5 decides (§3.2, OQ-1.5-12).
- Scheduled monthly re-crawl using the `recrawl` check: V1 hook; V0 re-crawls are manual (R-17, F-10).
