# 2.5 Crawl Orchestration & Lifecycle: Task List

Source: [2.5 spec](../2.5-crawl-orchestration-lifecycle.md) · decisions applied: F-62 (70% rule: only `ACCEPTED` counts, `NEEDS_REVIEW` not yet, capturable pages only, later approvals only improve), F-57 (active-time clock), F-64 (crawler stays running for the half-open probe), F-45, F-46, F-32, F-10, F-18, F-53 · status: draft

**Reading notes.** 2.5 runs in `worker-app` (loops and the `ev.orchestrator` consumer) and holds no browser code (R25). Every status change is one Postgres transaction with a compare-and-set, a `capture_job_change` row and any `emit` (spec §3.6). Cross-Part dependencies name the other Part's task by description where its number is not known yet (`<part>: <what>`); replace with `<part>-Tnn` when that list is published. Fixture ids are 2.11's (§5.4.1, §5.4.3 and §5.4.10 of the harness spec). Unit-level checks without a fixture id stay with 2.5 (2.11 §5.9). Jobs, units and events are 1.4's; breakers and the supervisor are 2.9's; discovery is 2.1's.

## Not in V0
- Scheduled re-crawl runs (`trigger = 'scheduled'`, monthly cadence, per-source cadence): V1 hook only; the run-creation core in T15 takes a `trigger` value but no scheduler is built (F-10, F-40; spec S15, OQ-2.5-20).
- `WAITING_FOR_AUTH` (V2, 7.1) and `WAITING_FOR_REVIEW` (no defined meaning): kept in the enum, no transition (R26, OQ-2.5-23).
- Per-crawl budgets (`max_browser_minutes`, `max_video_minutes`, `max_storage`, `max_AI_cost`): no decided values, not enforced; only the 30 active minutes, 25 pages and 1.6's throttle apply (R20, OQ-2.5-17).
- An automatic re-run of units on `site_recipe.activated`: the founder's click calls `retryUnits` (OQ-2.5-12 (d)).
- Pre-capture "unchanged" skipping on a re-crawl and a minimum interval between full crawls: hash-skip is 3.4's, after capture (R18, A15, OQ-2.5-16).
- A crawl manifest blob in storage: the crawl record is `crawl_run.selection`, `capture_job.rollup`, `capture_job_change` and 2.1's tables (OQ-2.5-21).
- Automatic pause on quality degradation (OQ-2.9-20) and a unit-level "running beyond deadline" backstop (2.9's sweeper and 1.4's reconciler own it; OQ-2.5-24).
- All screens (Crawl Jobs, attention list, run page, seed-review contact sheet, start dialog, admission banner): 6.4 and 4.4; 2.5 supplies the contracts only (§6).
- Discovery of new sites and any evasion of blocking: forbidden by F-46, DC-08 (no task).
- Dashboards, the dead-man's switch and the daily summary: 1.8.
