# 1.4 Job Queue, Events & Reliability: Task List

Source: [1.4 spec](../1.4-job-queue-events-reliability.md) · decisions applied: F-10, F-21, F-23, F-24, F-32, F-45, F-48 (OQ-1.4-5), F-54 (OQ-1.4-25), F-55, F-57 (OQ-1.4-26) · status: draft

Conventions for this list. 1.4 is the heart of "never stuck", so every state transition (the T-rows of §3.8), every reconciler step (§5.4), the lease and heartbeat rules, the intake holds and the event outbox each have a task with a check; the [coverage map](#coverage-map) at the end proves it. "1.5-Tnn" ids refer to the [1.5 task list](1.5-tasks.md); Parts whose lists are written in parallel are described, not numbered (for example "2.9: lease sweeper"). Fixture ids are from [2.11](../2.11-collection-test-harness.md) §5.4; where none exists the Check names an own test. The 2.11 harness runs fixtures against the whole stack, so a fixture check that needs 2.9, 2.2 or 2.10 is finally run in 1.4-T88; until then the task is checked with the fake supervisor of 1.4-T17.
