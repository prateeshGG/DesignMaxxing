Reading notes. "Crawler machine" is the founder's computer (F-45). Cross-Part dependencies use `<part-id>-Tnn` where the other list's number is known to be fixed; otherwise they name the function or artifact, e.g. `1.4: createUnits`. Fixture ids are the 2.11 catalogue ids ([2.11 spec](../2.11-collection-test-harness.md) §5.4.1). The spec's own (P) names are used as written (OQ-2.1-1 default).
