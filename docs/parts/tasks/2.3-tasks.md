# 2.3 Page & Section Capture: Task List

Source: [2.3 spec](../2.3-page-section-capture.md) · decisions applied: F-45, F-46, F-58, F-61 (and the wave-3 review names in [review-wave-3](../review-wave-3.md)) · status: draft

How to read this list. Task ids are `2.3-Tnn`; tasks of other Parts are named by what they deliver (their numbers are not fixed yet), for example "2.2: `AttemptContext` and the `pageCapture` slot". 2.3 is a module inside the 2.2 capture child: it has no database access, makes no request of its own and never judges publishability. Checks use the 2.11 catalogue ids. A hazard fixture has two kinds of expectation (2.11 H7): **required** is safe failure (the hazard is flagged `hazard_unresolved`, the unit is never ACCEPTED on that account, nothing is published automatically; DC-16) and **target** is that the technique succeeds; the checks below name both. "Run the fixture" means the standalone child run (`harness run --fixture <id>`) unless a gate-scope run is named. F-61 applies throughout: capture uses the branded Google Chrome channel, so every fixture run and the spike use it.

## Not in V0
- Visual (pixel-based) segmentation: `visual` stays a reserved value of `section.detection_method`; weak maps are flagged `segmentation_weak` and the spike counts the failure rate (OQ-2.3-10, S5).
- Forcing reveal styles, hiding any element, or converting bottom-anchored fixed layers to absolute positions for one shot: not adopted unless a hazard fixture proves it is needed and restores cleanly (OQ-2.3-13, R14).
- Any interaction state (menus, tabs, accordions, toggles, carousel controls): owned by 2.7 [V1] (R4).
- Tablet and laptop profiles, layout signatures, breakpoints: 2.8 [V1].
- The scroll-pass video (F-13) and every media extraction: 2.4 and V1.
- Crop execution, `section_crop` derived rows and `section`/`section_artifact` rows: 3.2 (the pure library here is what it calls; the gate cuts its own crops in memory, OQ-2.3-2).
- Choosing the better pass per section and writing `is_selected`: 2.10 only (OQ-2.3-16); 2.3 supplies `pass_hint`.
- Section type labels, OCR, text screening, change hashes, embeddings: 4.3, 4.2, 3.3, 3.4, 4.5.
- Content of cross-origin iframes, closed shadow roots and canvas pixels (R21, E22).
- A numeric `stability_diff` from the child and per-section stability frames: 2.10 computes the difference (OQ-2.3-17); per-section frames are an open request (OQ-2.10-41).
- A second dismisser pass between the settle pass and the first shot: only if the spike shows late overlays are frequent (OQ-2.3-24).
- Link discovery from the DOM snapshot's anchors: V0 never follows a link (R34, A13).
- Interaction-to-next-paint timing: `inp` stays null in V0 (R24).
