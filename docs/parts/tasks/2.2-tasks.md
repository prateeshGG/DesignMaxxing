# 2.2 Browser Capture Runtime: Task List

Source: [2.2 spec](../2.2-browser-capture-runtime.md) · decisions applied: F-10, F-11, F-12, F-16, F-17, F-20, F-32, F-45, F-46, F-58 (OQ-2.2-8, OQ-2.2-10: declared English locale and UTC, one honest user-agent, phone emulation), F-61 (OQ-2.2-34: branded Google Chrome channel) · status: draft

Reading notes. "Crawler machine" is the founder's computer (F-45). Cross-Part dependencies use `<part-id>-Tnn` where the other list's number is fixed; otherwise they name the function or artifact, e.g. `1.4: heartbeat`. Fixture ids are 2.11 catalogue ids ([2.11 spec](../2.11-collection-test-harness.md) §5.4). The child never touches Postgres, Redis or object storage (R2), so nothing here calls `putBlob` or `withLease`; that is 2.9's. Names marked (P) in the spec are used as written. Where a check says "request to 2.11", the fixture is not yet in the 2.11 catalogue.

## Not in V0
- Tablet profile and capture-context columns (theme, orientation, touch and hover capability): V1, owned by 2.8 (§3.2, §3.4).
- Interaction capture (menus, tabs, accordions, toggles) and the dangerous-action policy: V1, owned by 2.7 and 2.6 (§1 out of scope, F-16).
- Authenticated sessions and `session_ref` / `storageState`: V2, owned by 7.1; V0 rejects the field in the schema (F-17, §3.4).
- Observe-only wrappers around `requestAnimationFrame`, `getContext` and `Element.animate`: not installed until the founder answers OQ-2.2-32; only the empty `ctx.probes` slot exists (2.2-T07).
- Freezing `Date` or randomness: not in V0 (OQ-2.2-9); the static pass uses reduced motion and the freeze style only.
- Matching robots rules against subresources: V0 records them only (OQ-2.2-27); counsel input is due before the public library.
- A hosted-browser fallback: never used to evade a block (doc 22 DC-08); not built.
- Uploading artifacts and committing results, leasing, spawning and killing the child, breakers and the disk guard: 2.9 and 1.4.
- Section and media capture, gate checks, challenge signatures and the pixel-level seam check: 2.3, 2.4, 2.10.
