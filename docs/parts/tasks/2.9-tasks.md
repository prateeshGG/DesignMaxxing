# 2.9 Supervisor, Watchdogs & Circuit Breakers: Task List

Source: [2.9 spec](../2.9-supervisor-watchdogs-circuit-breakers.md) · decisions applied: F-45, F-46, F-48, F-53, F-54, F-55, F-56, F-57, F-64 (and the wave-2/3 review names in [review-wave-2](../review-wave-2.md), [review-wave-3](../review-wave-3.md)) · status: draft

How to read this list. Task ids are `2.9-Tnn`; tasks of other Parts are named by what they deliver (their numbers are not fixed yet), for example "1.4: lease functions". "Crawler machine" is the founder's own computer (F-45). Where a spec section still says `releaseLease(shutdown)` for the disk hard stop, `SpoolFull`, a runtime outage, sleep or power loss, the binding rule is the wave-2 review: cause `host_unavailable` (1.4 T5c and T13b; F-54), no attempt used. `shutdown` stays for `SIGTERM` and the founder's stop. Fixture ids are the 2.11 catalogue ids; a harness run of a fixture ("harness run --fixture <id>") is the check.

## Not in V0
- A second crawler machine and a `worker-app` copy of the lease sweeper: the sweeper is cheap and idempotent, so adding it later needs no code change; revisited when the database goes online (§5.5, OQ-2.9-24, R28 hook).
- Automatic quality-driven breaker trips: V0 has manual `breaker open` and `probe` only, with an alert from 1.8 (E24, OQ-2.9-20).
- Events for global breakers, disk-guard levels and session ends: needs a 1.4 envelope change (§4.6, OQ-2.9-21).
- Any evasion of a block (proxy or IP rotation, fingerprint spoofing, CAPTCHA solving, shortening a cooldown): forbidden, never built (R16, DC-08).
- Starting at boot, an always-on service, powering off or sleeping the computer, and the on-demand VM start/stop of doc 22: replaced by F-53 and the founder-started session (§5.11).
- Sandbox hardening of the capture container, secrets handling and the network firewall: owned by 1.7 (T08 only consumes the profile).
- Dashboards, alert rules and the dead-man expectation rules: owned by 1.8 (T60 and T62 only feed them).
- Janitor job roll-up and `closeUnits` calls: owned by 2.5.
- Operating runbooks: owned by 8.4.
- A new `expireLease` cause `host_suspended`: not needed, because `host_unavailable` (F-54) is already in 1.4.
